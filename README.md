# MFT (Machine Findings Template)

This repository contains write-up templates of solving lab machines. You can use it in any machines, including HackTheBox, TryHackMe, OffSec Labs, VulnHub, and many more.

## Templates

You can copy the template and use it to write down any interesting findings on the machine
- 🌲 Active Directory Machine Writeup Template
- 🐧 Linux/NIX Machine Writeup Template
- 🪟 Windows Machine Writeup Template

## Usage Guide

Once you downloaded or cloned this repository, make sure to either copy/duplicate them into your Obsidian's write-up directory or import these into Notion Pages.

### Importing Markdown Files to Notion

1. Hover to the _Meatballs Menu_ (`⋯`), then choose _Import_.
2. Click _Text & Markdown_ button, then select all Markdown files in _Templates_ directory that you have cloned.
3. Now that you have imported all files, you can duplicate files depending on machine OS that you are currently working on.
